User Activity Audit

"Track Every User's Operation on All the Objects of the System"

This Module Allows You to Track All Operations Performed on Data Models by The Users.

Description

This module allows privilege users to track user operations/activities performed on data models such as create, read, write and delete. It allows granted users track every user's operation/activity on all the objects of the system. This module provides high flexibility in configuration based on organization policy; depending on what activity or user should be tracked, allows to select different users and activities, data models or objects.

Odoo standard module report.

Key Features

  • Ability to track all operations performed by users.

  • High discretion to select multiple users or objects or fields.

  • Ability to search activities with different dimensions for example user, type, record id, object, date etc.

  • High flexibility in creating audit rules.

  • Multi-dimensional list of logs according to the pre-defined rules.
