Business Rules

"Configure Validation in Any Object"

This module allows administrator to defined business rules for any object dynamically from Odoo interface.

Description

Business rules describe the operations, definitions and constraints that apply to an organization. With the help of this module you can apply business rules to people, processes or any object of the system. This module allows to define many forms of business rules for any object dynamically from Odoo interface.

Key Features

  • Create, display, edit, and delete different validation groups.

  • Create and modify various validation rules.

  • High flexibility in generating and triggering various warning message.

  • Ability to search, track and review validation logs by multiple dimensions.

  • High flexibility in creating validation groups and rules.
